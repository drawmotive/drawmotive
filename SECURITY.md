# Security reporting

This policy covers the public Editor JavaScript API, compiled browser runtime
and copied assets in this repository. Include the package version, OS, browser,
hosting conditions, a minimal reproduction and the expected security impact.
Remove secrets and unrelated private documents from reports.

GitHub private vulnerability reporting is enabled. Use
[Report a vulnerability](https://github.com/drawmotive/drawmotive/security/advisories/new)
to submit a private report. Do not post exploit details publicly.

Use the [public issue tracker](https://github.com/drawmotive/drawmotive/issues)
for ordinary bugs and support questions without sensitive details.
