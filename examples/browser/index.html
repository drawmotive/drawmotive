Your page, your data

Embed the same editor.

Install the package, copy its runtime assets, and give it an element with a height. Save the exported document wherever your application stores data.

npm install @drawmotive/editor
npx drawmotive-copy-assets public/editor

View this page’s JavaScript · Read the API guide

import { initializeEditor } from '@drawmotive/editor';

const editor = await initializeEditor({
  container: document.querySelector('#editor'),
  assetBaseUrl: '/editor/',
  source: 'User -> Application -> Database',
});

// Export both a shareable image and editable data.
const { png, raw } = await editor.exportDocument();
await editor.importDocument(raw);

// Clean up when your component unmounts.
await editor.dispose();
