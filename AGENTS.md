# Public Repository Authoring

- Write repository-authored documentation, source comments, interface text, diagnostics, test names, scripts, configuration descriptions, and agent instructions in English.
- Keep public READMEs and explanatory prose entirely in English, regardless of the conversation language.
- Preserve intentional multilingual fixture data used to verify Unicode, fonts, localization, or user content; explain it in English.
- Preserve upstream license notices, attributed quotations, and third-party data in their original form.
- Apply this policy to nested packages and worktrees as well as this checkout.
- Use standard npm commands and committed package locks for installation and verification.
